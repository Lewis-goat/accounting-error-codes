QuickBooks Error H202: What It Means and How to Fix It

Error H202 is one of the most-encountered QuickBooks Desktop errors in multi-user setups, and it has a precise meaning: this workstation tried to open a company file that lives on another computer, and it could not reach the QuickBooks database service on that host. The company file itself is almost never damaged — H202 is a networking and hosting configuration error, which is good news, because configuration is fixable in an afternoon.

The name to know is QuickBooks Database Server Manager: on whichever computer holds the company file, this installs as a Windows service (named QuickBooksDBXX, where XX is your QuickBooks version number) that lets other machines open the file. H202 means something in that chain — hosting mode, the service, or the network path — is broken.

Fix 1 — Set hosting correctly (five minutes)

Only the computer that physically holds the company file should host. On each machine running QuickBooks, open File → Utilities:

  • On the server: you should see "Host Multi-User Access" (meaning it can be enabled — leave it enabled) and "Stop Hosting Multi-User Access" listed.
  • On workstations: you should see the option to start hosting — meaning they are not hosting, which is correct.

A workstation that accidentally hosted the file is the single most common H202 cause, especially after someone copied the file locally to work from home and put it back.

Fix 2 — Check the database service on the host

On the computer holding the file, press Win + R, type services.msc, and find QuickBooksDBXX (XX matches your version, e.g. QuickBooksDB34 for 2024):

  1. Right-click → Properties.
  2. Startup type: Automatic — so it survives reboots.
  3. If it is not Running, click Start.
  4. From the workstation, reopen the company file.

Fix 3 — Rescan with Database Server Manager

Still on the host, open QuickBooks Database Server Manager (Start menu → search "database server manager"), and Scan Folders → Add the folder containing your .QBW file → Scan. This registers the folder for multi-user access. After a server migration or folder move, this step alone clears H202.

Fix 4 — Firewall and ports

The database service listens on a specific port (visible in the Server Manager's System tab). Firewall software — especially after a Windows update — may have started blocking it. The clean fix is Intuit's: add a firewall port exception for QuickBooks and QBDBXX on both the host and workstations, for private and public profiles. Temporarily disabling the firewall to test confirms the diagnosis; do not leave it off.

Fix 5 — Run File Doctor when in doubt

The QuickBooks Tool Hub (free from Intuit) includes QuickBooks File Doctor, which automates the whole diagnosis: hosting mode, service state, network connectivity and folder permissions, in one pass. If File Doctor reports connectivity OK but H202 persists, ping the server by name from the workstation and check the mapped network drive still connects — stale drive mappings after a router or PC rename are the last classic cause.

When to stop

If every machine agrees on hosting, the service runs, the folder is scanned, and the firewall is open — but H202 persists — the remaining suspects are a corrupted installation of Database Server Manager on the host (reinstall it from your QuickBooks installer's ThirdParty folder) or deeper network policy (VPN mesh, domain firewall). That is Intuit-support territory, and your data is never at risk while you sort it.

The pattern to remember

H202, H505 and H101 form a family: all three mean "could not reach the host" in slightly different flavors (multi-user open, database connection, and hosting respectively). If you fix H202 properly — hosting, service, firewall — you generally fix the family.

Fixes above follow Intuit's documented H202 procedure. This page is general information, not Intuit support; verify against the help article for your version.

Frequently asked questions

What does QuickBooks error H202 mean?

H202 means this copy of QuickBooks Desktop cannot open the company file because it is hosted on another computer and the connection to that host failed. The file itself is usually fine — the problem is hosting configuration, the database service on the server, or a firewall blocking the connection.

Can I fix H202 myself?

Usually yes. Verify that only the server hosts multi-user access, confirm the QuickBooksDBXX service is running on it, and let QuickBooks Database Server Manager rescan the folder holding the company file. The QuickBooks File Doctor tool automates most of this diagnosis.

Does H202 mean my company file is damaged?

No — H202 is a connectivity error, not file corruption. Damage codes look different (the -6000 series). Fixing H202 does not require repairing the file.

What is the QuickBooks File Doctor?

A free Intuit tool, installed as part of the QuickBooks Tool Hub, that diagnoses and automatically repairs both company-file damage and network/hosting setup problems. For H202 it checks hosting mode, the database service and firewall rules in one pass.

Why did H202 start after a Windows update?

Windows updates commonly reset firewall rules or stop services. After any server reboot, check that the QuickBooksDBXX service restarts (set it to Automatic) and that the firewall still allows QuickBooks through on both private and public network profiles.
