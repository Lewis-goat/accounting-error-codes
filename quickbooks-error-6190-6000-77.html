QuickBooks Error -6190, -6000, -77: Company File Mismatch, Fixed

QuickBooks error -6190, -6000, -77 (often shown as "Error -6190, -816" or just "6190" on its own) stops you at the worst moment: the file will not open, and the number alone says nothing. The meaning is precise: the company file (.QBW) and its transaction log (.TLG) have fallen out of agreement — the log contains entries the file does not, so QuickBooks refuses to open rather than risk recording on top of an inconsistent state.

Understanding the pair matters. Every company file has a shadow transaction log sitting next to it (YourCompany.QBW.TLG) that journals every change. If the file is copied, restored, synced by Dropbox/OneDrive, or closed during a crash, the two can disagree — and the -6190 family appears.

Fix 1 — Quick Fix my Program (Tool Hub)

Intuit's documented first step for this family. Install the free QuickBooks Tool Hub from Intuit, open it, choose Program Problems → Quick Fix my Program. It closes stray QuickBooks processes and repairs common open/close faults. Roughly a minute; try opening the file after.

Fix 2 — Restart everything, in order

The mismatch is sometimes just a stale lock from another session:

  1. Close QuickBooks on every computer.
  2. Restart the server (the machine holding the file).
  3. Restart the workstations.
  4. Open the company file on the server first, then from a workstation.

Cloud-sync folders (Dropbox, OneDrive, Google Drive) holding a live company file are a standing cause of this family — the sync agent copies the QBW and TLG at different moments, manufacturing exactly this mismatch. Company files belong on the server or locally, synced only as backups.

Fix 3 — Run File Doctor

QuickBooks File Doctor (in the Tool Hub, Company File Issues tab) checks and repairs file damage and the network connection. For -6190 it verifies the QBW/TLG relationship and reports whether file damage underlies the mismatch.

Fix 4 — Rename the TLG (the documented fix, with its guardrail)

If the above does not clear it, Intuit's procedure is to rename the transaction log so QuickBooks builds a new one:

  1. Make a fresh backup first — this is Intuit's own instruction, and the point of the TLG is disaster recovery; you want the backup before removing that safety net.
  2. Find YourCompany.QBW.TLG next to the company file.
  3. Rename it to YourCompany.QBW.TLG.OLD.
  4. Open the company file. A new TLG is created automatically.

Fix 5 — Restore the most recent backup

If File Doctor reports file damage, stop creating new data and restore the most recent backup instead of forcing the file open. An accountant's repair (or Intuit's data-services team for severe cases) works from the backup; the more you use a damaged file, the fewer options they have.

The family map

  • -6190, -816 / -6189, -816: TLG/QBW mismatch — this page.
  • -6000, -77: file cannot be opened, permission or path flavor of the same family.
  • H202: cannot reach the host at all (see our H202 guide).
  • 6123, -6123, 0: connection or firewall flavor when opening over a network.

If -6190 recurs weekly, the cause is usually structural: cloud-sync on the data folder, or workstations opening the file by double-click through a mapped drive instead of QuickBooks' Open dialog. Fix the structure and the error stops returning.

Fixes follow Intuit's documented procedure for the 6189/816 and 6190 family. This page is general information; verify against the current help article for your version.

Frequently asked questions

What does QuickBooks error -6190, -6000, -77 mean?

QuickBooks Desktop cannot open the company file because the file (.QBW) and its transaction log (.TLG) do not match — the log records transactions the file does not. It typically happens after a file is copied, restored or closed incorrectly in multi-user mode.

Is my data lost?

No. The mismatch is bookkeeping between two files, not destruction. The transaction log exists precisely so QuickBooks can reconcile differences. Follow the fix order and only touch the TLG file after a backup exists.

Why do I need to delete the TLG file?

When the log no longer matches the file — after a bad copy or an interrupted session — the fastest documented repair is to rename the .TLG so QuickBooks generates a fresh one. Intuit's guidance is explicit: make a backup first, because the TLG is your recovery file if the QBW is damaged.

What is Quick Fix my Program?

A one-click repair in the free QuickBooks Tool Hub that shuts down QuickBooks processes and fixes common open/close problems. It is Intuit's documented first step for the -6190 family and takes under a minute.

How is this different from H202?

H202 is a network error — you cannot reach the computer hosting the file. -6190 means you reached the file but its internal pair of files disagree. H202: connection. -6190: consistency.
